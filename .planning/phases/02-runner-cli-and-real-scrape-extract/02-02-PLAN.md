- `_system_resolve(host) -> list[str]`: the deduplicated address strings from `socket.getaddrinfo(host, None, type=socket.SOCK_STREAM)`.
- `is_public_address(ip) -> bool`: parse with `ipaddress`; unwrap an IPv4-mapped IPv6 address first; return False when the address is private, loopback, link-local, multicast, reserved or unspecified, or not `is_global` (this covers 10/8, 172.16/12, 192.168/16, 127/8, 169.254/16, 100.64/10, fc00::/7 and 224/4, which `is_global` alone misses).
- Import `same_site`, `page_gate` from pagegate (re-exported from fetch for callers).
- `PageFetcher(cache_dir, *, http=None, resolve=None, sleep=time.sleep, clock=time.monotonic, min_interval=None)`. When `resolve` is None it calls the module attribute `_system_resolve` at call time, and when `min_interval` is None it reads the module attribute `POLITE_INTERVAL_S` at call time (so the conftest autouse fixture can keep every test offline and fast). Counters: `http_calls` (page requests, one per hop) and `robots_calls`.
- `fetch(url, site=None) -> PageResult`. `site` defaults to the URL host with a leading "www." removed. Order: (1) a scheme other than http or https gives unavailable "bad_scheme" with no request and no cache write; a host outside `same_site(host, site)` gives unavailable "off_site" with no request; (2) the page-cache lookup serves an entry only when its stored `guard_version` equals GUARD_VERSION (cached pages are then served before any robots or network work, so a rerun makes zero requests); an entry with a missing or different `guard_version`, which includes every entry written by Phase 1, is a miss, goes through every guard below and is overwritten, so no pre-guard entry can bypass robots, the address guard or the gate; (3) robots for the URL's scheme and host (below): disallowed gives unavailable "robots_disallowed" (cached); unreachable gives status "error" with reason "robots_unreachable", "dns_failure" or "transport_error" and the page is not requested (not cached); (4) the live request loop below; (5) cache ok and unavailable results only.
- Live request loop, used for pages and for robots.txt: for each hop (at most MAX_REDIRECTS redirects), resolve the hop's host (socket.gaierror gives status error "dns_failure"; any non-public address gives unavailable "private_address", no request sent), wait out the per-host politeness interval using the injected clock and sleep, then stream GET with `follow_redirects=False`, the existing TIMEOUT and the User-Agent header. A 301, 302, 303, 307 or 308 with a Location header is joined against the current URL with `httpx.URL.join`; the target must be http or https and `same_site(target host, site)`, else unavailable "off_site_redirect" with an error naming the target host; exceeding MAX_REDIRECTS gives unavailable "too_many_redirects". For a final response keep the Phase 1 mapping with reason codes: 5xx and 429 give status error "http_<code>", any other non-2xx gives unavailable "http_<code>", a page that is not text/html gives unavailable "not_html" (robots.txt skips this check). Read the body in chunks up to the byte cap (MAX_BYTES for pages, ROBOTS_MAX_BYTES for robots) and stop with status error "deadline" once `clock() - start` exceeds FETCH_DEADLINE_S. Transport errors (`httpx.HTTPError`) give status error "transport_error" with `type name: message` as the error text, as today. Record the last hop URL as `final_url`.
- Robots per RFC 9309, memoised per scheme and host on the instance and stored on disk in the page cache directory under a key derived from `robots:` plus the scheme and host (status code and body text, HTTP responses only): a 2xx body is parsed with `urllib.robotparser.RobotFileParser().parse(lines)` and checked with `can_fetch(USER_AGENT, url)`; a 4xx (including 401 and 403) allows everything; a 5xx or 429 means complete disallow for that host, surfaced as the page error "robots_unreachable"; a transport or DNS error is surfaced with its own reason and is not stored. Never call `RobotFileParser.read()` (no timeout control).
- Sanitise before extracting text: parse with BeautifulSoup and lxml, remove script, style, noscript, template, iframe, svg, object and embed elements, input elements of type hidden, every HTML comment node, every element with a `hidden` attribute, `aria-hidden="true"`, or an inline style declaring `display: none` or `visibility: hidden` (whitespace and case insensitive). Capture links from the remaining `a[href]` elements: absolute via `urljoin(final_url, href)`, http or https only, fragment removed, deduplicated in page order, anchor text stripped and cut to 80 characters, at most MAX_LINKS. Then run `trafilatura.extract` on the sanitised markup with the existing arguments, falling back to the sanitised soup's `get_text(" ", strip=True)`, and cut to MAX_CHARS.
- Gate at the fetcher: compute `extracted_chars = len(text)` from the extracted string after the MAX_CHARS cut and BEFORE any field is cleared. When `page_gate(text)` returns a reason, return unavailable with that reason, `text=None`, `chars=extracted_chars`, the captured links and the final URL. Otherwise return ok with `text`, `chars=extracted_chars` (equal to `len(text)`), links and final URL. `chars` is never computed from `text=None`; the invariant is "chars is the extracted character count" for ok and unavailable pages alike, and the cache-read path only re-derives `chars` from text for ok pages, as today.
- Cache writes: store `{**page.model_dump(), "guard_version": GUARD_VERSION}` for ok and unavailable results (errors are never cached), drop the `guard_version` key before building a PageResult on read, and write robots.txt entries with the same version key and the same mismatch-is-a-miss rule.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline to prospect web servers | Every request goes to third-party hosts the operator named; their responses (status, redirects, HTML, robots.txt) are untrusted |
| DNS answers to the fetcher | A public-looking name can resolve to an internal address |
| fetched HTML to LLM prompt | Page text, including hidden markup, is untrusted input to extraction |
| scraper to site owners | Fetch volume and robots.txt compliance are a courtesy and a defensible practice |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-08 | Elevation of privilege (SSRF) | `PageFetcher` request loop | high | mitigate | http and https only; every hop's host is resolved and refused when any address is private, loopback, link-local, CGNAT, multicast, reserved or unspecified (IPv4-mapped unwrapped); `follow_redirects=False` with a manual loop of at most 5 same-site hops; tested per address class and per redirect case |
| T-02-09 | Repudiation / non-compliance (robots.txt) | robots handling in `PageFetcher` | medium | mitigate | robots.txt fetched per host with the project user agent and parsed per RFC 9309 (4xx allow, 5xx and 429 complete disallow, transport error stops the host); a disallowed URL is never requested; the verdict is cached so reruns do not refetch |
| T-02-10 | Denial of service (hostile or slow sites, runaway crawl) | `PageFetcher`, `scrape_domain` | medium | mitigate | 10 s read and 5 s connect timeouts, 1.5 MB page and 500 KB robots caps, 20 s wall-clock deadline per fetch, 1 s per-host politeness, at most 3 attempts per kind, 14 fetches and 60 s per domain, 200 captured links, homepage-error short circuit |
| T-02-11 | Tampering (hidden prompt injection) | sanitiser in `fetch.py` | medium | mitigate | script, style, noscript, template, iframe, svg, object, embed, hidden inputs, comments and hidden or aria-hidden or display:none elements are removed before text extraction and link capture; `test_hidden_elements_and_comments_never_reach_text` plants a marker in each |
