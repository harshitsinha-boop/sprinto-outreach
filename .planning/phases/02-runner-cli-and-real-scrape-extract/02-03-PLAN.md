## Phase Goal

User runs one command on a file of domains and each domain is safely scraped and turned into schema-validated, evidence-quoted company data, with one bad domain never stopping the batch.

User-story framing: not available (ROADMAP Phase 2 Goal is outcome-phrased; no story invented per MVP rules).

## This plan

Deepens the extract slice behind the same runner. Task 1 replaces the skeleton's four-field profile with the full EXT-01 profile, where every value carries its own quote and source URL, and adds the deterministic check that keeps only quotes found verbatim on the page they cite. Task 2 hardens the prompt against hostile page text (escaped page tags, instruction lines removed before prompting, the same text used for validation), proves the call has no tools, and proves end to end that planted instructions cannot change the validated output. Phase 3's scorer and Phase 5's drafter consume this profile.

Purpose: ROADMAP Phase 2 success criterion 5 (EXT-01, EXT-02, EXT-03).

Output: `src/outreach/extract.py`, the CompanyProfile family in `src/outreach/models.py`, `stage_extract` and the score and draft helpers updated in `src/outreach/stages.py`, and `tests/test_extract.py`, with `tests/test_llm.py` and `tests/test_skeleton_e2e.py` moved to the new schema.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fetched page text to extraction prompt | Visible page text is attacker-controllable and enters the model's context |
| model output to the decision trail | The model's JSON becomes the company facts every later stage trusts |
| pipeline to Gemini free tier | Page text leaves the machine for a third-party model provider |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-15 | Tampering (prompt injection in visible page text) | `extract.prompt_text`, `build_extract_prompt`, `EXTRACT_SYSTEM` | high | mitigate | Instruction-like lines are removed before prompting; page-tag sequences inside text are escaped so a page cannot close its block or open a fake one; the system instruction declares page text untrusted; validation uses the same prompt text, so a quote from a removed line is dropped; `test_injected_page_yields_same_validated_profile_as_clean_page` and the e2e test prove invariance |
| T-02-16 | Tampering (fabricated or hallucinated facts) | `extract.validate_profile` | high | mitigate | Every kept value needs a quote of at least 8 characters found verbatim (whitespace-normalised) on the exact page its source_url names; unknown URLs, wrong-page quotes and paraphrases are dropped and logged; a failing scalar becomes null; `as_of` dates must also appear on the page |
| T-02-17 | Elevation of privilege (side-effect tools given to the model) | `extract.extract_profile`, `llm.build_config` | high | mitigate | The extract call goes through `generate_structured`, which has no tools parameter, and `build_config` never sets tools or tool_config; `test_extract_call_passes_no_tools` checks the recorded call, the signature and the config |
| T-02-18 | Repudiation | extract-stage record in run.json | medium | mitigate | `pages_used`, `evidence_total`, `evidence_kept`, every `evidence_dropped` reason and `injection_suspected_pages` are stored per domain, so each fact and each rejection can be traced to a page |
| T-02-19 | Tampering (planted text makes the model omit true facts) | extraction model behaviour | low | accept | The deterministic guard can only remove values; an omission biases the profile toward unknown, which Phase 3 scores as unknown (score interval), never as a negative fact |
| T-02-20 | Information disclosure (page text sent to the Gemini free tier) | extraction prompt | low | accept | Prompts hold only public pages from the company's own site; no Hunter contact data or keys enter the extract prompt; noted in STACK.md as acceptable for public company websites |
| T-02-21 | Denial of service (prompt size and cost) | `build_extract_prompt` | low | mitigate | At most six usable pages of at most 8000 characters each, one extract call per domain, validated output cached, and quota errors abort the batch (Plan 02-01) |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs; `re` and `html` are stdlib and pydantic was approved in Phase 1 |
